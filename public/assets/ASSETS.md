# Date Planner Assets

These V1 sticker assets are handmade SVGs created for this project:

- `heart-envelope.svg`
- `sticker-burst.svg`
- `calendar-heart.svg`
- `heart-clock.svg`
- `food-tray.svg`
- `speech-heart.svg`

They are not downloaded stock assets. The first image generation attempt was rate-limited, so the current app uses project-local SVG illustrations and emoji-style option icons. Generated PNG/WebP stickers can later replace these files without changing the component structure.
